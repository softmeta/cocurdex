# Support

Cocurdex is pre-release and provided without a support SLA.

Use GitHub Issues for reproducible bugs and focused feature proposals. Search
existing issues before opening a new one and use the provided issue forms.

Include the Cocurdex commit or version, operating system, architecture, agent
runtime, reproduction steps, and sanitized logs when relevant. Do not attach
credentials, private source code, personal data, or user and agent transcripts.

For informal questions, usage discussion, and quick feedback, join the Feishu
group by scanning this QR code:

<img src="docs/assets/feishu-feedback-group-qr.png" alt="Feishu group QR code" width="240" />

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be
reported publicly.

Questions about commercial licensing or trademark permission may be opened as
a non-confidential repository issue. Do not place confidential business terms
or personal information in a public issue.
