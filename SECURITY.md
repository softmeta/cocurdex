# Security Policy

## Supported versions

Cocurdex is pre-release. Security fixes are made on the latest `main` branch.
Older commits and local builds are not supported separately.

## Reporting a vulnerability

Do not report vulnerabilities in public issues, pull requests, discussions, or
social media.

Use the repository's **Security** tab and select **Report a vulnerability** to
open a private GitHub Security Advisory. Include:

- the affected component and version or commit;
- the operating system and architecture;
- reproduction steps or a minimal proof of concept;
- the expected impact;
- any suggested mitigation;
- whether the issue is already public or known to another party.

Remove credentials, personal data, proprietary source code, and unrelated user
or agent transcripts from the report.

Maintainers will review the report privately, coordinate a fix when confirmed,
and discuss disclosure timing with the reporter. Do not disclose the issue
before a fix or agreed disclosure date is available.

## Scope

Reports about Cocurdex code and packaged artifacts are in scope. Vulnerabilities
in third-party agent runtimes should also be reported to their respective
vendors. If Cocurdex makes a third-party issue exploitable in a new way, report
that integration issue here as well.
