Cocurdex 是一个**桌面优先的多 Agent 开发工作台**。它把对话、集成终端、编辑器和浏览器预览放进同一个工作台，让你并行运行多个 AI Agent，同时始终清楚哪个会话需要你处理。

本站是**面向用户的产品文档**。工程 ADR、计划和研究笔记存放在 monorepo 的 `docs/` 目录中，默认不会发布到这里。

## 心智模型

Cocurdex 围绕几个持久的理念构建：

1. **工作台，而非聊天窗口**——会话、对话、终端、编辑器和浏览器预览彼此并列。对话记录只是其中一个面板。
2. **并行会话**——同时运行多个 Agent，而不必合并到同一段对话历史里。
3. **如实的状态**——状态保持具体：思考中、正在使用工具、等待你处理、有未读结果。
4. **本地优先的产品数据**——笔记和 Issue 保存在本机的应用私有存储中。CLI 是受支持的外部边界；SQLite 文件不是公开 API。
5. **桌面写入，云端在后**——未来的团队控制台可能投射部分组织级数据。本机工作仍经由桌面 daemon 完成。

## 你会得到什么

| 形态 | 角色 |
| --- | --- |
| **桌面应用** | 运行 Agent、编辑文件、预览 UI、管理笔记/Issue 的主要场所 |
| **CLI(`cocurdex`)** | 打开文件夹，管理笔记/Issue/搜索/Skills/工作树，驱动会话与工作流——无需自己打开 SQLite |
| **产品 Skills** | 可选的 Agent skills(`cocurdex-*`)，用于围绕应用私有数据做 PRD → Issue → 交付 式的工作 |
